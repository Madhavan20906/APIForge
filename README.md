# 🚀 APIForge – API Debugging Tool

**APIForge** is a lightweight developer tool for building, testing, and analyzing API requests with rich response visualization. It provides an intuitive interface to inspect API responses in JSON, table, and tree formats—making debugging faster and more efficient.

---

## ✨ Features

### 🔧 Request Builder

* Supports **GET, POST, PUT, DELETE**
* Add **headers** dynamically
* Add **query parameters**
* Send **JSON request body**

### 📊 Response Visualization

* **JSON View** – formatted + syntax highlighted
* **Tree View** – expandable/collapsible structure
* **Table View** – auto-convert arrays into tables

### ⚡ Performance Insights

* Response status (200, 404, 500, etc.)
* Response time (ms)
* Payload size
* Highlights slow responses

### 🔍 Developer Utilities

* Search within JSON responses
* Copy full response or specific values
* Meaningful error messages (e.g., Unauthorized, Not Found)

### 💾 Productivity Features

* Save API requests as **Collections**
* View request history
* Re-run saved requests instantly

---

## 🖥️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **API Handling:** Fetch / Axios
* **Optional Backend:** Flask (for proxy & CORS handling)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/reqlab-project.git
cd reqlab-project
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```

---

## 🔐 Note on API Keys

Some APIs may require authentication. For production use:

* Avoid exposing API keys in frontend
* Use a backend proxy (Flask) for secure requests
